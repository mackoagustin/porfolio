Un tracker que avisa cuando un caso cambia de estado

Para una empresa del sector salud desarrollé una aplicación de escritorio conectada a la API de su sistema de pólizas. Detecta automáticamente los cambios de estado y muestra qué casos necesitan atención, para que el equipo deje de revisarlos uno por uno.

El problema

Saber qué cambió obligaba a revisar cada caso a mano

El equipo trabajaba con un sistema de pólizas que guardaba toda la información, pero no avisaba cuando algo cambiaba. Para saber si una póliza había avanzado, se había rechazado o necesitaba una acción, alguien tenía que entrar al sistema y abrir los casos de a uno.

Con muchos casos activos, ese control consumía horas, dependía de la memoria de cada persona y hacía que algunos cambios importantes se detectaran tarde.

La solución

Una app conectada al sistema que detecta los cambios sola

En lugar de reemplazar el sistema que ya usaban, construí una herramienta que se conecta a él mediante su API y trabaja encima de esa información.

  • Detección automática de cambiosLa app consulta la API y identifica qué casos cambiaron de estado desde la última revisión.
  • Un solo lugar para el seguimientoTodos los casos en un listado centralizado, en vez de entrar al sistema uno por uno.
  • Filtros que reflejan cómo trabaja el equipoPor estado, región y firma, para encontrar rápido lo que le toca a cada persona.
  • App de escritorioDesarrollada en Electron, para que el equipo la use como una herramienta más de su día a día.

El resultado

De perder la tarde buscando casos a saberlo en minutos

Hoy el equipo sabe en minutos qué casos necesitan atención, sin revisar el sistema caso por caso. El tiempo que antes se iba en controlar estados ahora se usa para resolver los casos que realmente lo necesitan.

Además, como la herramienta se integra con el sistema existente, no hubo que migrar datos ni cambiar la forma de trabajar del resto de la organización.

Tecnología

Cómo está construido

Aplicación de escritorio en Electron que se integra con la API del sistema de pólizas del cliente. La lógica de detección compara el estado de cada caso entre consultas para identificar los que cambiaron.

Preguntas frecuentes

Lo que suelen preguntarme sobre este tipo de integración

¿Hay que reemplazar el sistema que ya usamos?

No. La idea es construir encima de lo que ya funciona: me conecto a tu sistema y resuelvo la parte que hoy hacen a mano.

¿Qué pasa si mi sistema no tiene API?

Depende del caso. A veces hay exportaciones, bases de datos o integraciones alternativas. Lo primero es revisar qué ofrece tu sistema y desde ahí ver la mejor opción.

¿Tiene que ser una app de escritorio?

No. En este caso fue lo más práctico para el equipo, pero la misma solución puede ser una aplicación web o un panel interno.
