Laika · Producto · Fullstack

Del catálogo a la atención telefónica: producto y sistema para Laika

En Laika, un e-commerce de productos para mascotas, diseñé las herramientas internas que usa el equipo para logística, devoluciones, pagos y reglas de negocio, desarrollé el catálogo y construí un IVR conectado a una base de datos SQL para la atención telefónica.

El problema

Una operación con muchos estados, excepciones y canales

Un e-commerce en crecimiento acumula procesos que dependen unos de otros: un pedido pasa por logística, puede terminar en una devolución, tiene un pago asociado y está atado a un catálogo que cambia todo el tiempo. Cada uno de esos procesos tiene reglas y excepciones propias.

Cuando las herramientas internas no reflejan bien esas reglas, el equipo opera con ambigüedad y aumenta el margen de error. Y cuando los clientes llaman por teléfono, cada consulta depende de que alguien atienda y busque la información a mano.

La solución

Herramientas claras para el equipo, un catálogo ordenado y un IVR con datos reales

Trabajé tanto en el diseño del producto como en el desarrollo, desde las pantallas que usa el equipo hasta los sistemas que hay detrás.

  • Herramientas internasDiseño de los flujos de logística, devoluciones, pagos y reglas de negocio, para que cada estado y cada excepción se entiendan a simple vista.
  • CatálogoDesarrollo del catálogo de productos, la base sobre la que se apoyan la tienda y la operación.
  • IVR con base de datos SQLUn sistema de atención telefónica automatizada: cada llamada pasa por un menú de opciones que se apoya en una base de datos SQL antes de llegar a una persona.
  • Design SystemComponentes y criterios compartidos para que las herramientas mantengan coherencia a medida que crecen.

El resultado

Menos ambigüedad en la operación y una atención telefónica más ordenada

Quien opera el sistema todos los días toma decisiones con menos ambigüedad y menos margen de error, porque las herramientas reflejan cómo funciona realmente el negocio.

Del lado de la atención, el IVR ordena las llamadas antes de que lleguen al equipo, y la información que necesita cada consulta sale de la misma base de datos en lugar de buscarse a mano.

Preguntas frecuentes

Lo que suelen preguntarme sobre este tipo de proyecto

¿Qué es un IVR y para qué sirve?

Es un sistema de respuesta telefónica automática: quien llama elige opciones en un menú y el sistema lo guía o lo deriva según lo que necesita. Conectado a una base de datos, puede usar información real en lugar de respuestas fijas.

¿Se puede integrar con los sistemas que ya usamos?

En general sí. Lo primero es revisar dónde están hoy los datos que necesita la atención y desde ahí definir cómo conectarlos.

¿Hacés solo el diseño o también el desarrollo?

Las dos cosas. Puedo diseñar las herramientas, desarrollarlas, o hacer ambas, que es cuando mejor se nota que lo que se decide en una pantalla llega igual al sistema.
